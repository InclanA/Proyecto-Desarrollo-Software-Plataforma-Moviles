# NASA APOD
Una app que muestra imágenes del espacio de la NASA y cuenta un poco sobre cada una

# tecnologías y herramientas utilizadas
- react Nativ
- expo
- java script
- hooks personalizados
- componentes y props


# instalación y ejecución 

Instalar las dependencias

```bash
npm install
```

después se inicia Expo con el siguiente comando

```bash
npx expo start
```
una vez iniciado el sv se abre la aplicación con expo go y escanea el qr
